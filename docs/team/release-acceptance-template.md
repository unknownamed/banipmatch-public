# 최종 통합·제출 검수 기록 양식

이 파일은 **실행 전 양식**이다. 결과가 비어 있으면 통과가 아니다. [전체 완료 계획](completion-plan.md)의 F07~F12에 사용한다. 복사본을 `docs/team/handoffs/` 또는 민감 자료가 있으면 제외된 `local/`에 저장한다. 비밀값/식별자가 없는 요약만 공유한다.

## 실행 기준

- 검사자 / 실행일시(KST): 미기록
- main SHA / 적용 PR / 깨끗한 checkout 여부: 미기록
- Python·Node·OS / PC 조건 / 모의 또는 실제 키 소유자 환경: 미기록
- 입력 파일·해시 / 시나리오 ID / 실행 ID / 계획 버전: 미기록
- 기존 동결 실험 버전과 이번 실행의 차이: 미기록
- 실제 자료의 제공자·관측/수신시각·사용 범위 / 원문 보존 허용 여부: 미기록

## 판정과 남은 항목

- 중요 오류 / 담당 / 수정 커밋 / 관련 재검사: 미기록
- 조건부 보류(증거·대안·보고서 표현·책임자): 미기록
- 개발 완료 / 보고서 제출 완료 / 발표 제출 완료 / 공개 완료: 모두 미판정
- 다음 담당이 실행할 정확한 명령·필요한 사용자 행동: 미기록

범위 밖 항목은 이유와 근거를 남긴다. 필수 항목을 임의로 해당 없음 처리하지 않는다. 일부 공급자의 실제 조회 실패는 그 공급자 실패로 남기며 다른 공급자 성공과 합쳐 전부 통과로 표시하지 않는다.
