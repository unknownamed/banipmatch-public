# 엔진·프론트·API 병합 확인 · 2026-11-07

사용자는 필요한 변경만 관련자가 1회 검토하고 수정·검사 후 재승인을 기다리지 않는 [새 기준](../review-policy.md)을 적용했습니다. 병합 과정의 오류는 병합 담당 AI가 직접 수정·검사해 반영할 수 있습니다.

- **엔진 #1:** 선효의 복귀 후 위치 이동 누락·부적합 차량 경로 판정 지적을 수정했습니다. 엔진 51건·계약 29건·DB 32건과 CI 성공 후 main에 병합했습니다. 엔진 버전은 `0.1.1-b0-b1`입니다.
- **프론트 #4:** 사용자가 병합한 `43002dd`의 고정 도착/복귀 시각 감지, 제약 위반 지표명, 결과 대기·오류·B0 단독일 때 원안 유지 수정을 확인했습니다. 테스트 16건·타입 검사·빌드 통과, 추가 재현 결함은 발견하지 못해 코드는 그대로 유지했습니다.
- **API #3:** `aa903c7`에서 signed 64-bit 범위·정수형 실수 저장·롤백·필드 경로422와 Swagger 상대 서버 URL 수정이 확인됐습니다. API 45건 통과. 이후 최신 main과 문서·CODEOWNERS·CI 충돌 6곳을 정리하며 API 설명과 엔진·프론트·새 리뷰 규칙을 보존했습니다.
- **합친 작업 트리:** Python 검사 96건(API45+엔진51, 하위 사례49)·계약29·DB32 통과. CI는 계약 검사와 API·엔진 전체 검사를 모두 실행하며 중복 엔진 실행은 합쳤습니다. 배포한 `docs/development/v0.1/`은 수정하지 않았습니다.

실제 엔진을 API 실행에 연결한 것은 아닙니다. HTTP 클라이언트의 응답·오류 처리는 메모리 응답으로 확인했으며, 실제 서버와 브라우저 전체 연결·승인 POST·독립 일정 검사·운영 인증·배포는 완료로 표시하지 않습니다. 데이터 #5는 이번 병합 범위에 포함하지 않았습니다.

현재 소스와 최종 병합·CI 상태는 [#1](https://github.com/unknownamed/banipmatch/pull/1), [#3](https://github.com/unknownamed/banipmatch/pull/3), [#4](https://github.com/unknownamed/banipmatch/pull/4)에서 확인합니다. 팀원은 최신 main을 받고 기존 작업 브랜치에도 공통 변경을 반영합니다.
