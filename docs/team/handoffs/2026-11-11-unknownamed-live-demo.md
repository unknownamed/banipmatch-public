# 통합 시험 인계 · 2026-11-11

최신 사용자 요청은 팀원 구현을 통합하고 실제 API→화면·모의 이동·직접 계산 웹앱을 배포해 시험하는 것이다. 발표/보고서 재작성보다 구현 검수를 먼저 진행했다. 이번 임시 HTTPS 서버 실행은 대겸이 명시 요청했으며 이전 ‘AI 서버 실행 보류’를 이번 범위에 한해 갱신한다.

## 구현 및 실제 확인

- PR64/65 화면과 PR42 참고 자료 읽기를 통합했다. PR64 선효의 리뷰6건을 길웅 수정본과 대조해 반영하고, 응답 유실 재시도·세션 만료·원격 수신자 연결 갱신을 추가 보완했다. 길웅/선효의 실제 검토를 AI가 대신한 것으로 기록하지 않는다.
- HJNC 실제31행 수신, KMA 해양관측 HTTP200·거제도 부이1건, 특보 HTTP200·빈 자료를 화면에서 확인했다. 수신/관측 시각과 실패/오래됨/공백을 유지한다. 기상 원인/확정 마감 변경이나 실제 배차 계산 입력으로 승격하지 않는다.
- AIS 구독 확인 후45초 위치0건, 정상 연결 종료. [공식 형식 기반12척·671건 합성 재생](../../data/busan-fleet-replay.md)을 별도 화면에서 제공한다.
- ORS는 길웅의 [첫 Matrix 표본](../../data/ors-matrix-verification.md)을 최신 main에서 확인했다. 본 서버에는 ORS 키/검증된 업무 지점이 없어 실시간 연결·실차 도착 예측으로 표시하지 않는다. 카카오 지도도 키/배포 도메인 설정을 확인한 환경에서만 사용할 수 있다. 기본 지도는 OSM이다.
- HTTPS 주소에서 실제 B0~B3 계산·조정안 비교·독립 검사·B3 내부 승인을 확인했다. 별도2세션의 교차 조회404, 자기 조회200, CSRF/Origin403, 비공개 파일/구 v1 경로404를 확인하고 시험용2세션을 해제했다.
- Python643개+하위255개, 프론트150개 및 타입/빌드 통과(통합 검수 시점). 자동 검사 통과를 실기기 수신이나 현장 효과로 표현하지 않는다.

## 팀원이 확인할 것

각자 새 브라우저 창에서 시연 URL을 열고 같은 세션을 공유하지 않는다. 임시 URL은 테스트 요청 이슈에 안내한다. PC가 꺼지면 연결이 끊기므로 오류보고에는 시험 시각도 쓴다.

| 담당 | 테스트 |
|---|---|
| 길웅 | PC/휴대폰 폭에서 표·버튼·지도·조건입력 잘림, 모의 선박 재생/정지·수신 중단 표시, Android 또는 iPhone 수신 화면 |
| 민준 | 07 입력 누락 보완 후 재계산, 08 미확정 변경 차단, 실제/모의 구분·관측/수신 시각·결측 설명, 다른 휴대폰에서 알림 시험 |
| 선효 | 다른 세션 자료 차단, 확정 후 새 원안, 초대·구독·전달/재시도·이전 지시 차단, 담당자 응답 상태 |
| 대겸 | 팀원 재현 결과를 모아 수정·재검수, 최종 버전·상시 배포 환경 준비 |

모두 정상 입력에서 계산→비교→내부 승인도 한 번 확인한다. 실차·실기사 연락은 하지 않는다. 폰 알림은 시험 직전에 대겸이 만든 초대를 개인 전달받고 직접 허용해야 한다. 일반 방문자의 초대/발송 차단은 정상 동작이다.

오류는 **기기/브라우저·시각·누른 순서·기대한 결과·실제 결과·스크린샷**으로 이슈에 남긴다. 초대 링크의 `#invite=` 뒤 비밀이나 API키/구독정보는 캡처/본문에서 제외한다. 서버 장애와 자료0건·입력 부족을 구분한다.

## 아직 확인되지 않은 것

Android·iPhone의 실제 알림 도착→열람→응답 왕복은 팀원 실기기 검수 대기다. 상시 호스팅/고정 도메인, ORS 실제 연결·업무 지점 채택, 카카오 배포 도메인 연결, 현장 배차/GPS/실항차 매핑도 완료로 표시하지 않는다. 현재 테스트 배포가 공급자 운영 승인이나 현장 운행 실증을 대신하지 않는다.

실행법: [시험 배포](../../deployment/live-demo.md). 신규 읽기 계약: [reference-display-1](../../development/v0.2/reference-display.md). 새 API·통합 공개 경계는 최종 통합 PR에서 관련자1회 검토한다. 이 문서를 기존 계획/심사 범위를 확대하는 지시로 해석하지 않는다.
