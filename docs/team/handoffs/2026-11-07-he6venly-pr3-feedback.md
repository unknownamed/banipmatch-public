## 수정한 동작

1. SQLite INTEGER로 저장할 값을 signed 64-bit 범위로 검사함. 초과 시 500 대신 `422 INTEGER_OUT_OF_RANGE`와 원본 필드 경로 반환.
2. 실제 테이블의 INTEGER 컬럼을 기준으로 검사해 JSON에만 보관하는 값의 상한을 임의 변경하지 않음. 정수형 실수는 정확한 정수로 바인딩하며 입력 원본·해시를 보존.
3. 차량 등 검색 행을 일부 삽입한 뒤 실패해도 입력 원본·계획·검색 행·멱등 기록을 함께 롤백함.
4. 런타임 OpenAPI의 servers를 상대 주소 `/`로 변경. localhost·다른 포트의 Swagger가 예제의 127.0.0.1:8000으로 요청하지 않게 함. 접속·출처 허용 범위는 그대로 유지.
