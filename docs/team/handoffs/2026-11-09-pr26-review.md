# PR26 화면 검토·보완

PR26은 탐색 메뉴, 표·지표 디자인, 승인 진행 표시를 다듬는 프론트 변경이다. API·DB·엔진·공통 계약과 승인 조건은 바꾸지 않는다. 사용자 요청에 따라 AI 보조 검토와 오류 보완을 진행했다.

## 수정한 문제

새 마감 초과 표시에서 분 단위 반올림을 먼저 해 마감보다 20초 늦은 도착의 강조가 사라졌다. 초과 여부는 응답의 실제 시각 차이로 판단하고, 1분 미만은 그대로 표시하며 그 이상은 분·초로 표시한다. 미확인 도착을 지연이나 정상 도착으로 추정하지 않는다. 이는 표시 보완이며 엔진의 제약 판정을 바꾸지 않는다.

## 검토와 검사

- 승인 대기·진행·실패·결과 불명·성공, 다른 방법 승인 후 차단을 코드와 기존 검사로 확인했다. 진행 막대의 마지막 완료 표시는 실제 현재 방법의 승인 완료 상태에서만 나온다.
- 마감 이전·정각·20초·59초·60초·80초 경계 6개를 추가했다. 수정 전 3개 실패를 확인한 뒤 수정했고, 프론트 전체 101개와 기본 앱·읽기 전용 평가 화면의 타입 검사·빌드를 통과했다.
- Edge에서 1440/390 폭의 예제 화면, 페이지 오류 없음, 모바일 문서 가로 넘침 없음, 동작 줄이기 설정을 확인했다. 내부 표·일정의 가로 스크롤은 유지한다.
- 병합 후 실제 로컬 계산→비교→내부 승인→저장 계획 대조의 결과는 PR26 완료 댓글에 남긴다. 예제 화면 검수를 실제 승인 검수로 대신하지 않는다.

공개 게시·실제 운송사 데이터·외부 예약 변경·기사 통보는 이번 범위에 포함되지 않는다. 공개 평가용 정적 화면은 별도 산출물이며 기존 화면을 바꿨다는 이유로 실시간 서비스가 배포된 것은 아니다.
