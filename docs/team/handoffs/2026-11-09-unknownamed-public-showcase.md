# 황대겸 · 공개용 평가 기록 화면

기준 main: `bd14e0a` (PR23 평가 근거 병합). 독립된 `frontend/showcase/` 화면을 추가했다. 기존 로컬 앱·API·계산 엔진·승인 계약은 변경하지 않았다.

## 동작과 게시 범위

- 모의 입력의 보존된 실제 계산 결과10사례·시드0·B0~B3를 검색·선택하고, 전체80회·20쌍 맥락을 함께 본다. 원안/결과 일정·미처리 사유·고정 위험·목적 단계·별도 감사·원본 JSON을 확인한다.
- B2/B3가 같은 화물을 처리했는지 먼저 표시한다. 다른 작업 집합을 개선으로 포장하지 않고, 변경 감소와 이동 증가,50건에서 차이·전체 최적성이 없는 결과를 그대로 보여준다.
- `npm run build:showcase`는 별도 `dist-showcase/`를 생성한다. 기존 앱의 API·지도·환경 토큰·계산 요청·승인 화면을 불러오지 않는다. 쿼리로 기존 앱을 활성화할 수 없다.
- 정적 HTTP 호스팅에는 산출물3파일만 전달한다. `connect-src 'none'`, 상대 자산 경로, 소스맵·공용 폴더 제외, 가짜 환경 토큰·API 흔적 및 파일 경계 검사를 적용했다. CI 검토용 산출물 보관은 실제 공개 배포가 아니다.
- [실행·배포 안내](../public-showcase.md)와 실제 검수 이미지: [PC](../showcase-preview/desktop.png), [다른 처리 작업 경고](../showcase-preview/different-work.png), [모바일](../showcase-preview/mobile.png).

## 리뷰와 남은 일

최길웅이 `f9a8b86`을 검토한 뒤 보완본 `709fa9a`도 [확인 댓글](https://github.com/unknownamed/banipmatch/pull/24#issuecomment-6737161444)을 남겼다. 사용자가 요청한 새 보완본 확인 조건을 충족해 PR24를 `535e5ec`에 병합했다. 이 확인 조건은 PR24에 적용했으며 저장소 전체의 일반 리뷰 규칙을 바꾸지 않았다.

### 리뷰 제안 반영과 갱신본 검사

- 비교쌍·시드 수·B2/B3 분모·작업 규모별 변경/이동 범위를 보존 자료에서 계산한다. 처리 수와 처리 작업 집합이 모두 같은 쌍만 범위에 포함한다. 누락값은 0으로 바꾸지 않고, 최적성 집계가 분모와 모순되면 비율 대신 자료 확인 안내를 표시한다.
- 작업과 해 상태는 한국어 설명과 원문을 함께 표시한다. `FEASIBLE`이나 전체 목적 증명이 없는 `OPTIMAL`을 최적성 입증으로 읽지 않도록 구분한다. 원시 JSON과 검사·승인 값은 유지한다.
- 공개 화면 소스를 여러 줄로 정리했다. 새 실행 의존성·API·계약·평가 원본 변경은 없다.
- 갱신본 프론트 **78개** 검사, 기존 앱·공개 화면 타입/빌드, 환경 토큰 canary를 넣은 정적 파일 검사 통과. 이전 Python 검사는 위 초기 검증 기록이며, 프론트 수정만을 위해 같은 전체 Python 검사를 로컬에서 반복하지 않았다.
- 갱신본 Edge 검수: 10개 사례 지표 원본 대조·40개 방법 전환/일정 행·검색0건·PC/모바일·쿼리 무시·동적 요약·한글 상태 표시 확인. 페이지 오류0, 정적 GET6개, API/외부/변경 요청0. 로컬 검수 서버는 종료했다.
- [규모별 요약 화면](../showcase-preview/summary.png)과 PC·모바일·다른 처리 작업 이미지는 `709fa9a` 검수 당시 자료다. 이후 비교 가능 쌍이 없는 경우의 문구와 UNKNOWN·INFEASIBLE 설명도 보완했다. [병합 후 통합 점검](2026-11-09-integration-24-25.md)을 참고한다. 공개 게시는 아직 수행하지 않았다.

정적 평가 자료는 실제 실계산 앱의 대체물이 아니다. 실계산·내부 승인 시연은 PR22의 로컬 경로를 사용한다. 공개 호스팅 계정·URL·비용 및 실제 게시 검수는 아직 남아 있다. 운영 인증·다중 사용자 저장·실시간 계산 제한·실제 자료 이용조건은 해당 기능을 공개할 때 별도 구현·검증한다. 이번 작업에서는 가입·결제·외부 연락·연구실 서버를 사용하지 않았다.
