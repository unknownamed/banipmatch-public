# 황대겸 · 고정 작업의 작은 사례 독립 검산

기준 main `d5c42fc`. 생산 엔진·API·DB·화면·v0.1 계약을 바꾸지 않고 최적화 담당의 검증 공백을 보완했다. 기존 완전열거 검사는 고정 작업 없는 작은 사례를 다뤘고, 고정 예약은 개별 회귀로 확인하고 있었다.

## 추가한 검증

[`test_optimization_frozen_oracle.py`](../../../tests/engine/test_optimization_frozen_oracle.py)는 6개 테스트의 결정적10개 사례에서 B2/B3를 각각 검산한다. 한 대의 차량과2~3개 작업, 완전한 방향별 이동표, 정수 분 시각으로 범위를 제한했다.

| 사례 | 독립적으로 확인하는 조건 |
|---|---|
| 미래 고정 예약 앞의 정수 순번 여유 있음/없음 | 고정 순번을 바꾸거나 0·소수 순번을 만들어 작업을 끼워 넣지 않음 |
| 이미 출발한 작업의 순번 prefix | 기록을 보존하고 차량 가용 상태 이후 작업만 조정하며 이동을 중복 계산하지 않음 |
| 고정 작업의 마감·근무 초과 | 위험 작업을 삭제하거나 미처리로 돌려 목적을 좋게 만들지 않음 |
| 고정 작업과의 상대 순서 역전 | 고정 작업도 역전 참여 합집합에 포함하며 시각 변경과 중복 집계하지 않음 |
| 한 슬롯을 두 조정 작업이 경쟁 | B2는 짧은 이동, B3는 기존 작업 유지라는 목적 차이를 실제 선택한 작업 ID까지 대조 |
| 고정 작업으로 접근하는 이동 | 일정의 시간 제약에는 포함하고 조정 작업 이동 목적에서는 제외; 고정 뒤 배치도 확인 |

배정 여부·순서·정수 출발시각을 모두 열거해 최적 목적값을 구한다. 엔진의 내부 일정·지표·모형 헬퍼를 가져오지 않는다. 실제 반환 배정에서도 도착·복귀·접근·준비·시간창·근무·정수 순번·고정 보존을 직접 재계산하고, 반환 지표 및 각 최적화 단계의 값·하한·최적 상태와 맞춘다. 반환된 지표만 믿고 정답으로 삼지 않는다.

예를 들어 한 고정 예약 앞에 한 자리만 남고 원안 작업 JB의 이동이4분, 새 작업 JA의 이동이2분이면 B2는 JA를 선택하고 B3는 변경 없이 JB를 유지한다. 두 결과 모두 미처리1건이지만 처리한 작업이 다르므로 이동 또는 변경의 단순 개선율로 발표하지 않는다. 이 사례는 모형 목적을 설명하는 단위 검증이다.

## 검사 결과와 민감도

- 엔진 전체131개·하위134개 검사 통과. 목적 단계 대조 추가 후 새 파일6개·하위20개를 다시 확인했다. 최종 전체 CI 결과는 이 변경의 PR 실행 기록을 따른다.
- 별도 프로세스의 메모리에서만 네 가지 의도적 오류를 넣어 새 검사의 검출 여부를 확인했다: 순번 동률 허용, 고정 접근시간 삭제, 고정 작업의 역전 참여 누락, 고정 접근 이동을 이동 목적에 추가.
- 마지막 변이는 초기 유효안 보존 때문에 결과 지표 비교만으로 잡히지 않았다. 목적 단계의 값·하한까지 독립 목적값에 대조한 뒤 잘못된 증명 정보를 검출했다. 디스크의 생산 코드는 수정하지 않았고 실제 엔진에서 같은 오류가 발견됐다는 뜻은 아니다.
- 기존 CI는 `pytest`로 새 파일도 수집하므로 별도 검사를 끄거나 CI 범위를 바꾸지 않았다.

재현:

```sh
python -m pytest tests/engine/test_optimization_frozen_oracle.py -q
python -m pytest tests/engine -q
```

## 해석과 남은 범위

이 검증은 작은 유한 사례의 계약 모형 정확성을 보강한다. 모든 입력의 일반 증명, 선효 담당의 실제 결과 독립 검사·승인, 현장 효과 검증을 대신하지 않는다. 기존80회 평가·228회 개발 실험·공개 화면의 결과를 재계산하거나 덮어쓰지 않았다. 50건의 증명 시간 개선은 별도 개발 입력으로 수행할 연구이며 이번 검사 통과를 성능 개선으로 설명하지 않는다.

작은 담당 내부 검사와 사용자 요청의 협업 지침 구체화이므로 필수 사람 리뷰를 새로 요청하지 않는다. 실제 계산 동작·공통 계약 변경이 필요해지는 경우에는 그 변경 범위의 검토 기준을 따른다. AI 내부 검수를 팀원의 수동 승인으로 기록하지 않는다.
