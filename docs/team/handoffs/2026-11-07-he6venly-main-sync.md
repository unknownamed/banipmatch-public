- 현재 계약 v0.1·배포 원본·업무 필드 변경 없음. main 동기화 시점의 인계이며 최종 제출 상태는 PR 본문 참조. 배포 미수행

## 내 파트에서 수정한 것

- Swagger 등 동일 출처 POST도 외부 출처와 같이 거절해 `403 ORIGIN_NOT_ALLOWED`가 발생했음
- localhost·127.0.0.1의 API 서버 자체 출처로 재현한 검사 2건이 수정 전 실패
- 현재 서버와 동일한 출처는 허용하도록 수정. loopback·모의 토큰·외부 출처 허용 목록 검사는 유지
- Python 3.12.10에서 API 29건 통과. API·DB 계약은 main에서 바뀌지 않아 배포 원본 검수의 불필요한 반복은 하지 않음
- 엔진을 전역 미구현으로 표시하던 문구를 정정. B0/B1은 별도 PR #1 검토 중이며 이 브랜치 API에는 미포함·미연결
