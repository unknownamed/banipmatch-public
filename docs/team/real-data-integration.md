# 실제 자료 검증·연결 작업

기준일: 2026-11-09. 추가 요청으로 [개인 신청 안내](personal-api-signup.md)의 기상청·AIS·ORS 담당 발급/표본 준비도 지금 병행한다. 제품 채택은 검증 후이며 기존의 조건부 후보 문구를 신청 보류로 해석하지 않는다. 사용자는 모의 시연만으로 개발을 끝내지 않고, 실제 자료가 판단과 시연에 도움이 되면 검증해서 연결하도록 요청했다. 모의 배차와 실제 항차·도로 자료를 함께 사용할 수 있다. 자료가 실제라는 이유만으로 모든 기능에 채택하지는 않는다.

현재 운영 앱의 외부 API 자동 연동은 미완료다. 아래는 담당별 실행 계획과 확인 근거이며 새 API/DB 계약이 아니다. PR27·29의 표본 감사와 기존 지도 표시를 재구현하지 않는다. 기존 v0.1 규격과 동결 평가 자료는 보존한다.

### HJNC에서 이번에 확인한 범위

- [공식 선석 현황](https://www.hjnc.co.kr/esvc/vessel/berthScheduleT)의 공개 조회 경로에 `dateType=week`, `startDate=2026-11-09`, `endDate=2026-11-15`, `amount=10`, `page=1`로 **1회** 요청했다. 재시도·주기 수집은 하지 않았다.
- 수신시각 `2026-11-09T12:51:14Z`, HTTP200, 5,739바이트, 항차10개. 원본 SHA-256은 `a2f90a10eeeaa5d70798996280851ae10c64228518c3e207f425672067138743`이다. 원본·요청 URL·수신기록은 개인 로컬에 보존하고 Git에는 올리지 않았다.
- `total`/`totalElements`는24, 실제 받은 행은10, `hasNext=false`였다. 공식 화면은 `total / amount`로 페이지를 구성한다. `hasNext=false`만 보고 전부 받은 것으로 처리하지 않는다. 요청 기간보다 앞선 값도 있어 기간 범위와 최신성이 확정된 표본이 아니다.
- 이 조회의 수신시각은 공급자의 변경 발생시각이 아니다. 원본 시각에는 시간대가 없으므로 한국시간이라고 임의 변환하지 않는다. 이전 표본과 겹치는 항차가 있더라도 수신기록·조회조건·의미를 먼저 대조해야 한다.
- [이용약관](https://www.hjnc.co.kr/esvc/board/terms) 제22조는 서비스 정보의 사전 동의 없는 **영리 목적** 복제·전송·배포 등을 제한한다. 이를 모든 비영리 연구 금지로 확대하지 않는다. 반대로 반복 수집 빈도·보관·공개 시연·재배포 허용 범위와 숫자 한도는 아직 확인하지 못했다.
- [CCT 공지](https://www.hjnc.co.kr/board/notice/detail?no=1381)의 특정 적용 범위를 모든 항차·화물에 일반화하거나 모든 마감을 `ETB - 10시간`으로 계산하지 않는다.

### 도로공사 신청과 첫 응답 검증 — 민준 담당

1. 기존 발급자가 있는지 확인한다. 없으면 [제공기관 인증키 발급](https://data.ex.co.kr/openapi/apikey/requestKey)에서 본인 정보로 신청한다. 공식 화면은 요청 즉시 발급·이메일 전송을 안내한다. 실제 발급 결과는 담당자가 별도로 기록한다.
2. [공공데이터포털 항목](https://www.data.go.kr/data/15076793/openapi.do)은 LINK형이며 [제공기관 실시간 영업소간 통행시간](https://data.ex.co.kr/openapi/basicinfo/openApiInfoM?apiId=0147)으로 연결된다. 포털의 개발 자동승인/운영 심의 안내와 제공기관 직접 발급 경로를 구분한다. 공공데이터포털의 다른 키를 그대로 쓰지 않는다.
3. 현재 제공기관 Python 예제 경로는 `https://data.ex.co.kr/openapi/trtm/realUnitTrtm`. 요청 인수는 `key`, `type`, `iStartUnitCode`, `iEndUnitCode`, `iStartEndStdTypeCode`, `sumTmUnitTypeCode`, `numOfRows`, `pageNo`다. **인수 코드값은 현행 안내/응답을 확인하고 넣는다.**
4. [구판 공식 PDF](https://data.ex.co.kr/guidedown/openoasis_guide.pdf) p21의 `/odhour/upDownTrafficTime`, `carType`, `timeAvg`(초)는 다른 경로다. 현재 상세 필드 안내는 조회 오류가 있어 단위·차종·시간대·집계/방향 코드가 미확인이다. 구판 단위를 새 응답에 이식하지 않는다.
5. 필요한 영업소 쌍과 역방향을 소량 호출한다. 응답 표본에서 원본 구간·방향·관측/집계시각·수신시각·차종·단위·누락·페이지를 기록한다. 키가 들어간 요청 URL/로그는 저장·공유하지 않는다. 성공, 빈 구간, 오류를 구분하며 빈 시간은0으로 채우지 않는다.
6. [이용약관](https://data.ex.co.kr/portal/guide/useSite) 제7조의 1인1키·본인 사용·타인 제공 금지, 제13조 출처 표시를 따른다. **키를 선효나 Git/채팅에 넘기지 않는다.** 보유자가 허용 환경에서 수집하고, 공유 가능한 표본/정규화 결과·검증 기록만 인계한다. 공용 서버의 본인 키 운영 범위가 불명확하면 확인 전 공유 배포하지 않는다.
7. 카탈로그는 무료·이용허락범위 제한 없음으로 안내하지만 [제공기관 정책](https://data.ex.co.kr/portal/guide/publicDataPolicy)과 키 약관도 함께 적용한다. **숫자로 된 일/월/초당 한도는 미확인**이다. ‘실시간/수분 단위’ 안내를 특정5분·15분 갱신 보장으로 쓰지 않는다. 한도·캐시·호출 주기는 공식 증거/계정 안내가 확인될 때 기록하고, 여러 키로 한도를 합치지 않는다.

## 실제·참고·모의를 연결하는 기준

- 항목별 출처와 의미를 유지한다. 실제 항차 + 모의 배차표 + 가정한 화물 준비시각은 혼합 자료다. 화면에 ‘실제 API’ 배지만 붙여 전부 실자료처럼 보이게 하지 않는다.
- v0.1의 `data_mode`와 근거 종류·출처·관측/수신시각을 활용할 수 있는지 먼저 확인한다. 하나의 근거 묶음 안에서 서로 다른 출처를 표현할 수 없다면 데이터·API·프론트가 개정안을 함께 검토한다. 이 문서가 새 필드나 상태 문자열을 자동으로 계약에 추가하지 않는다.
- **현재 실행 제약:** 스키마에는 `mixed`가 있지만 `backend/api/storage_checks.py`는 `simulated` 이외의 입력 저장을 `422 DEMO_DATA_ONLY`로 거부한다. 선효 담당 후속에서 혼합 자료의 저장·독립 검사·내부 승인·공개 시연 경계를 함께 검토해야 한다. 이 제한만 삭제하거나 혼합 자료를 `simulated`로 위장하지 않는다. 본 준비 작업은 제한을 바꾸지 않았다.
- 공식 시각 의미/시간대·단위와 업무 필드 매핑을 확인해야 엔진 입력으로 변환한다. 확인 전에는 원문 표본 감사·참고 화면 준비를 진행하고, 엔진의 필수 값을 추측해서 채우지 않는다.
- 같은 출처·터미널·항차의 서로 다른 시점 자료에서 `YARD_OPEN`/`YARD_CLOSE` 차이를 비교한다. 관측 차이는 공급자가 확인한 변경 사건과 구별한다. 공급자 변경시각이 없으면 알 수 없는 값으로 남긴다. 조회에서 사라졌다고 취소·반입 금지를 만들지 않는다.
- 변경이 확보되지 않으면 **‘실제 항차에 가정한 마감 변경’** 사례로 재현한다. 실제 관측 변경 횟수·현장 효과로 집계하지 않는다. 자료 시각을 오늘로 이동한 경우에도 그 변환은 모의다.
- 도로 구간 시간에 일반도로 접근·대기·서비스·복귀를 임의로 합쳐 확정 전체시간으로 만들지 않는다. 가정 부분은 분리하고 민감도 분석한다. 출발·고정 작업은 그대로 보존한다.
- 호출 실패 시 모의 자료로 자동 대체하지 않는다. 실패/마지막 성공 시각/오래된 자료 여부를 표시하고, 사용자가 명시적으로 선택하는 모의 모드를 구분한다. 오래된 자료를 현재 확정 변경이나 승인 가능한 입력으로 자동 승격하지 않는다. 재시도 상한·호출량·캐시와 수집 주체를 정한다. 캐시/원본 보존은 제공사별 허용 범위에 한하며, 카카오 REST 길찾기의 응답 저장 금지에는 적용하지 않는다.

## 지금 쓸 수 있는 로컬 관측 비교 도구

PR29의 [표본 감사](../data/source-collection-2026-11-09.md)에 더해 `tools/compare_hjnc_observations.py`를 준비했다. 네트워크 요청·생산 데이터 변환·엔진 실행은 하지 않는다.

```powershell
python tools/compare_hjnc_observations.py --current local/current.json --current-received-at 2026-11-09T12:51:14Z --output local/single-report.json
python tools/compare_hjnc_observations.py --previous local/previous.json --previous-received-at 2026-11-09T01:00:00Z --current local/current.json --current-received-at 2026-11-09T12:51:14Z --output local/pair-report.json
```

파일과 시각은 설명용 자리이며 실제 보관 파일·실제 수신시각으로 바꾼다. 출력 경로는 새 파일이어야 한다. 단일 관측/공통 항차 없음은 비교 불가, ETB만 바뀐 경우는 반입시간 변화와 분리한다. 원문 시간대는 미확인 상태로 보존하고 기존 파일을 덮어쓰지 않는다. 해시 키는 항차 비교용이며 익명화·사용 허가를 보장하지 않는다. 보고서는 호출자가 제공한 캡처 형식을 검사할 뿐 원본의 진위까지 인증하지 않는다.

## 이번 작업의 경계

실제 자료를 검증해서 연결하는 방향과 도로공사 신청 담당 배정은 승인됐다. 유료 계약·새 외부 메일·실제 기사 연락·연구실 자원·공개 배포는 이번 요청에 포함하지 않는다. 기존 문의 회신을 확인하되 임의 재촉/중복 발송하지 않는다. 본인 인증·필수 정보·약관 판단이 필요한 담당자는 구체적으로 요청하고, 자료 검증과 합성 응답 기반 연결 준비는 병행한다.
