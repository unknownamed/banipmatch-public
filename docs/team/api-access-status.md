## 2026-11-09 황대겸 · 기존 문의 회신 확인

- 11월6일 발송한 자문5곳(심재훈 교수·김흥섭 교수·BPA·HJNC·컨테인어스) 및 SeaVantage API 시험 문의의 기존6개 메일 대화를 조회했다. 각 대화에는 발신 메일1건만 있었으며, 관련 발신자/기관 도메인 검색에서도 이번 조회 범위의 수신 답장은 확인되지 않았다. 상대가 읽지 않았거나 지원을 거절했다고 단정하지 않는다.
- 원문·수신자·메일 식별자는 개인 로컬 발송/확인 기록에 보관한다. 공유 저장소에는 연락 상태와 필요한 자료 조건만 기록한다. 신규 문의·재촉 발송·계정 신청·키 발급은 하지 않았다.
- 기존 BPA 문의에는 확정 반입시간·변경 이력과 보고서/발표 사용 조건이 포함돼 있다. 기존 HJNC·컨테인어스 문의는 공개 항목·빈 양식·가상 예시 중심이며, **실제 배차 원안 제공을 요청하거나 확보한 상태가 아니다.**
- [PR27의 자료 확보 기준](../data/source-collection-2026-11-09.md#남은-수집-요청과-완료-기준)에 따라, 이후 사용자가 추가 연락을 요청하면 동일 항차의 변경 전후와 당시 입력·원안을 연결할 수 있는지, 비식별 작업/차량 ID·고정 상태·시간·이동/서비스 조건 및 보고서/팀 공유/공개 시연 허용 범위를 함께 묻는다. 기존 질문을 그대로 중복 발송하지 않는다.
- 엔진 개발은 키 없이 계속 가능하다. 응답 수신·사용 조건 확인 전 실제 자료 연동 완료나 현장 효과 검증 완료로 상태를 올리지 않는다. 다음 확인은 담당자의 후속 작업 또는 회신 알림 때 진행하며, 자동 재촉 메일은 설정하지 않는다.
