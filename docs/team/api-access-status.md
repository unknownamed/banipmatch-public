## 상태 갱신 양식

서비스 행 아래에 다음 양식으로 실제 진행 기록을 추가하고 위 표를 갱신합니다. 진행 증거가 없으면 예상 상태를 완료로 바꾸지 않습니다.

```text
ID / 서비스:
담당 / 계정 소유자: 이름만, 이메일·비밀번호·키 값 제외
확인일:
상태: 미확인 / 준비 중 / 가입 완료 / 신청 접수 / 승인·발급 / 응답 확인 / 보류·반려
신청한 기능·필드:
접수일 / 제공사 명시 처리기간: 미공개이면 미확인
다음 확인일:
비용·일/월/속도 한도·집계 단위:
키 사용 주체·팀원 접근 조건:
저장·보고서·발표·공개 시연 허용 범위:
응답 시험 범위 / 아직 확인하지 못한 것:
공식 근거 URL / 비밀값 제거한 증거 파일:
막힌 점 / 필요한 본인 인증·판단:
```

본인 전용 키는 다른 팀원에게 넘기지 않습니다. 키 소유자가 직접 허용 환경에 설정하고, 연결 담당에게는 키 이름·설정 위치·검증 결과만 전달합니다. 별도 업체 승인이 필요한 경우에는 그 승인 범위 안에서만 팀 서버·공개 시연에 연결합니다.
