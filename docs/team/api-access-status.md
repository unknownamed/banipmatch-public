### 2026-11-09 실제 자료 작업으로 갱신

- 담당 이슈: [민준 #30](https://github.com/unknownamed/banipmatch/issues/30), [선효 #31](https://github.com/unknownamed/banipmatch/issues/31), [길웅 #32](https://github.com/unknownamed/banipmatch/issues/32), [대겸 #33](https://github.com/unknownamed/banipmatch/issues/33). 도로 신청은 #30에 포함되며 실제 접수/발급 상태를 그 이슈와 이 표에 남깁니다.
- 도로공사 AP-09는 나중 후보 C에서 **즉시 검증 A**로 올렸습니다. [발급 페이지](https://data.ex.co.kr/openapi/apikey/requestKey), 현재 `/trtm/realUnitTrtm` 예제와 구판 경로의 차이, 본인 키 공유 금지·숫자 한도 미확인을 [검증 계획](real-data-integration.md)에 명시했습니다. 발급은 담당자가 진행할 일이며 아직 접수/발급 증거가 없습니다.
- HJNC 11월9일12:51:14Z 공개 조회1회는10행/전체표시24를 받았습니다. 원본/수신기록은 로컬 보존. 단일 관측 비교 도구를 준비했으나 실제 변경 이력·운영 앱 연동 완료는 아닙니다.
- SeaVantage·기상·AIS는 조건부 C입니다. 기존 문의를 취소하거나 권한을 잃었다는 뜻이 아니라 HJNC/도로 검증을 우선한다는 작업 순서입니다.

### 2026-11-09 공개 자료 조사 추가

- **AP-02:** [HJNC 공개 조회 1회 응답10행 확인](../data/source-collection-2026-11-09.md). 인증된 연구 API·계정 승인과 별개다. 기간 필터/페이지 처리·시간대·저장/시연/재배포 조건·변경 전후 이력은 미확인. 기존 문의의 승인 상태를 변경하지 않는다.
- **AP-09:** [실시간 영업소간 통행시간 현행 공식 카탈로그](https://www.data.go.kr/data/15076793/openapi.do) 확인. 무료·개발단계 자동승인/운영단계 심의승인 안내. 키·실응답·구간 적용은 미확인이며 전체 운송 경로의 시간으로 사용하지 않았다.
- 참고 공개 파일: 광양항 서부컨테이너터미널 CSV 원본 확보·품질 검사. 값이 있는58,171행과 빈168,046행을 구분하고 시간 불일치도 기록했다. HJNC 자료나 핵심 입력으로 교체하지 않았다.
- AP-01의 과거 API 상세 주소3개는 이번 조회404. 현행 신청 메뉴는 별도 확인 필요. 가입·신청·신규 연락·반복 수집은 실행하지 않았다.

## 상태 갱신 양식

서비스 행 아래에 다음 양식으로 실제 진행 기록을 추가하고 위 표를 갱신합니다. 진행 증거가 없으면 예상 상태를 완료로 바꾸지 않습니다.

```text
ID / 서비스:
담당 / 계정 소유자: 이름만, 이메일·비밀번호·키 값 제외
확인일:
상태: 미확인 / 준비 중 / 가입 완료 / 신청 접수 / 승인·발급 / 응답 확인 / 보류·반려
신청한 기능·필드:
접수일 / 제공사 명시 처리기간: 미공개이면 미확인
다음 확인일:
비용·일/월/속도 한도·집계 단위:
키 사용 주체·팀원 접근 조건:
저장·보고서·발표·공개 시연 허용 범위:
응답 시험 범위 / 아직 확인하지 못한 것:
공식 근거 URL / 비밀값 제거한 증거 파일:
막힌 점 / 필요한 본인 인증·판단:
```

본인 전용 키는 다른 팀원에게 넘기지 않습니다. 키 소유자가 직접 허용 환경에 설정하고, 연결 담당에게는 키 이름·설정 위치·검증 결과만 전달합니다. 별도 업체 승인이 필요한 경우에는 그 승인 범위 안에서만 팀 서버·공개 시연에 연결합니다.

## 2026-11-09 황대겸 · 기존 문의 회신 확인

- 11월6일 발송한 자문5곳(심재훈 교수·김흥섭 교수·BPA·HJNC·컨테인어스) 및 SeaVantage API 시험 문의의 기존6개 메일 대화를 조회했다. 각 대화에는 발신 메일1건만 있었으며, 관련 발신자/기관 도메인 검색에서도 이번 조회 범위의 수신 답장은 확인되지 않았다. 상대가 읽지 않았거나 지원을 거절했다고 단정하지 않는다.
- 원문·수신자·메일 식별자는 개인 로컬 발송/확인 기록에 보관한다. 공유 저장소에는 연락 상태와 필요한 자료 조건만 기록한다. 신규 문의·재촉 발송·계정 신청·키 발급은 하지 않았다.
- 기존 BPA 문의에는 확정 반입시간·변경 이력과 보고서/발표 사용 조건이 포함돼 있다. 기존 HJNC·컨테인어스 문의는 공개 항목·빈 양식·가상 예시 중심이며, **실제 배차 원안 제공을 요청하거나 확보한 상태가 아니다.**
- [PR27의 자료 확보 기준](../data/source-collection-2026-11-09.md#남은-수집-요청과-완료-기준)에 따라, 이후 사용자가 추가 연락을 요청하면 동일 항차의 변경 전후와 당시 입력·원안을 연결할 수 있는지, 비식별 작업/차량 ID·고정 상태·시간·이동/서비스 조건 및 보고서/팀 공유/공개 시연 허용 범위를 함께 묻는다. 기존 질문을 그대로 중복 발송하지 않는다.
- 엔진 개발은 키 없이 계속 가능하다. 응답 수신·사용 조건 확인 전 실제 자료 연동 완료나 현장 효과 검증 완료로 상태를 올리지 않는다. 다음 확인은 담당자의 후속 작업 또는 회신 알림 때 진행하며, 자동 재촉 메일은 설정하지 않는다.
