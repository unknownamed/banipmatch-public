# API 사전 신청·준비 안내

기준일: **2026-11-09 (한국시간)**. 최신 [개인 신청 목록·링크·한도](personal-api-signup.md): 민준 기상청(#35), 선효 AIS(#36), 길웅 ORS(#37)를 지금 준비합니다. 사업자/기관 자격 없이 개인이 진행하는 경로이며 본인 인증·약관은 필요합니다. [실제 자료 검증·연결 작업](real-data-integration.md)이 최신 실행 방향입니다. 모의 시연과 병행해 유용한 실자료를 확인하고, 검증을 통과한 범위부터 연결합니다. 가입·신청·발급·실응답 상태는 [진행표](api-access-status.md)에 구분합니다.

## 누가 무엇부터 할지

| 담당 | 지금 할 일 | 조건을 갖춘 뒤 이어갈 후보 |
|---|---|---|
| **심민준 · 데이터** | **도로공사 키 보유 확인 → 없으면 본인 명의 즉시 신청 → 첫 응답 검증**. HJNC 시간대·항차 키·범위·이용조건 검증, 체인포털 현행 신청 경로 확인 | 기상청 일반회원·키를 지금 준비하고 해양 관측/특보 소량 검증. 허용 표본 정규화 |
| **최길웅 · 프론트** | 기존 카카오맵 유지, ORS 개인 무료 Standard 신청과 거리/시간 수치 검증 준비, 자료 구분 표시 | 배포 도메인·현재 쿼터 확인. 길찾기는 별도 권한 |
| **안선효 · API·통합** | 수집 담당·캐시·실패/마지막 성공 상태·읽기 전용 연결 준비 | AIS 개인 무료 키를 지금 준비해 작은 해역 시험. ORS 서버 시험 협조. 문자·결제는 별도 결정 |
| **황대겸 · 엔진·팀장** | 관측 비교·혼합 사례 채택 기준·기존 문의 회신 정리 | 검증된 실제 입력으로 새 비교. 화물 추적은 권한/표본이 있을 때 |

기존 본인 전용 키를 다른 사람에게 전달하지 않습니다. 본인 인증은 명의자가 수행하고, 팀 멤버 기능·공용 서버 허용 범위는 제공사 조건을 따릅니다.

## 우선순위와 상태 공유

- **A · 핵심 자료 검증:** 도로공사는 기존 보유 확인 후 미보유 시 개인 신청합니다. HJNC·체인포털/BPA는 기존 접근·공개자료·현행 신청 자격을 검증하며 이번 즉시 개인가입 대상에는 넣지 않습니다. 기존 문의·계정의 중복을 피합니다.
- **B · 지금 개인 신청·검증:** 기상청·AISstream·ORS Standard. [담당별 절차](personal-api-signup.md)를 따릅니다. 카카오맵은 기존 앱과 표시를 재사용합니다.
- **C · 협의/추가 조건 후보:** SeaVantage/ShipsGo·카카오 자동차 길찾기·SOLAPI. 카카오 REST는 개인 사용 가능하나 응답 저장 금지여서 저장형 엔진 자료로 바로 채택하지 않습니다. HJNC/BPA 연구 API도 일반회원 가입과 별도 API 승인을 구분합니다. 유료 계약과 외부 발송은 별도 요청입니다.

**다음 담당 작업 세션에** 보유 확인/신청 접수/발급/실응답/막힌 이유와 다음 행동을 남깁니다. 과거 11월8일 내부 목표를 미래 마감으로 재사용하지 않습니다. 제공사 승인 기한을 보장하지 않으며, 승인 대기 중에는 합성 응답으로 연결 검사를 준비합니다.

- **현재 기록:** 대겸은 과거 본인인증 뒤 가입 완료를 확인하지 못했습니다. BPA 자문은 이미 발송했습니다. 이번 문서 작성 중 로그인·신청·회신 확인은 하지 않았습니다.

- **한도·대기:** 문서상 Web SDK 일 300,000건, 전체 API 무료 월 3,000,000건을 함께 확인합니다. 앱 기준이며 조원별 키로 합산 증설하지 않습니다. 일반 활성화 절차는 있으나 처리시간 SLA는 확인하지 못했습니다.
- 지도는 배경입니다. 실제 차량 GPS·선박 위치·화물 추적 자료를 공급하는 API가 아닙니다.

- **키 소유:** 본인만 사용하고 양도·대여하지 않는 조건입니다. 민준이 소유·수집을 맡고 선효에게 키를 전달하지 않습니다. 공용 서버 운용 가능 여부가 불명확하면 본인 환경에서 수집한 허용 자료나 모의 응답으로 연결합니다.
- 기상은 시각·구역을 함께 보여주는 보조 근거입니다. 악천후와 지연이 겹쳤다는 이유만으로 지연 원인을 확정하지 않습니다.

- API 이용 전 본인 휴대전화 SMS 인증이 필요합니다. 자동승인과 연락처 인증 완료는 별개로 확인합니다.

## B3 · AISstream — 안선효, 심민준과 자료 형식 확인

- **링크:** [GitHub 로그인·키 관리](https://aisstream.io/account) · [가입 순서](https://aisstream.io/) · [서버 연결·제한](https://aisstream.io/documentation).
- **준비 순서:** 본인 GitHub로 로그인 → API 키 생성 → 키는 본인 서버 환경에 보관 → 부산 신항 주변의 작은 해역으로 짧은 수신 시험 계획. 등록/발급만 하고 실제 장시간 수집을 켜 두지 않습니다.
- **대기·한도:** 공개 안내는 로그인 후 키 생성 절차이며 승인 기간 보장은 없습니다. 계정당 구독 연결 3개, 출발 IP당 연결 3개 제한을 함께 적용합니다. 일/월 수신 총량 숫자는 미확인입니다.
- **연결:** 브라우저 직접 연결은 허용되지 않으므로 서버가 받고 화면에는 필요한 데이터만 전달합니다. 표시·저장·발표 허용 조건과 원하는 해역의 실제 수신 범위를 확인해야 합니다.
- AIS는 선박 관측입니다. 트럭·개별 컨테이너 GPS가 아니며 중국 연안/항만에서 항상 끊김 없이 받을 수 있다고 보장하지 않습니다. MMSI와 IMO·항차 ID 연결 및 관측시각을 보존합니다.

## B4 · ORS Standard — 최길웅, 안선효·황대겸 협조

[개인 무료 가입](https://account.heigit.org/signup) 후 [플랜](https://account.heigit.org/info/plans)·키를 확인합니다. 첫 범위는 저장 조건을 확인한 거리/시간 수치이며 카카오 길찾기의 저장 제한을 우회하는 대량수집이 아닙니다. 새 주소·무료량·CC-BY-SA·화물차/교통 한계와 완료 기준은 [개인 신청 안내](personal-api-signup.md#ors-standard--길웅-선효대겸-협조)를 따릅니다.

## 신청 목적에 쓸 공통 문장

> 국립창원대학교 컴퓨터공학과 학생팀 반입맞춤입니다. 스마트물류 경진대회에 참가해 보고서와 발표, 모의 시제품을 준비하고 있습니다. 부산항 신항 수출 컨테이너의 확인된 반입시간 변경에 대응해 배차 조정안을 비교하려 합니다. 허용된 자료를 읽기 전용으로 사용하고, 수집 빈도·보관기간·대회 발표 및 시연 범위는 제공기관 조건에 따르겠습니다. 현재 실제 운송사 배차표와 실화물 식별번호는 확보하지 못했습니다.

서비스마다 필요한 필드와 목적을 추가합니다. 웹사이트가 없으면 임의 주소를 만들지 말고 로컬 개발 단계임을 밝힙니다. 비공개 저장소 링크를 상대가 열람할 수 있다고 가정하지 않습니다.

## 준비 완료로 인정할 것

1. **가입**, **API 신청 접수**, **승인/키 발급**, **허용된 응답 수신**을 별도 상태로 기록합니다.
2. 신청한 서비스/필드, 신청일, 공식 승인 예상기간(없으면 미확인), 다음 확인일, 비용·한도·키 사용 주체·표본/발표 이용조건을 진행표에 남깁니다.
3. 키·OTP·비밀번호·개인 식별값이 없는 화면/요약만 저장합니다. 실제 화물 원본은 허용 범위와 공개 범위를 검토한 뒤 취급합니다.
4. 계정·키를 여러 개 만들어 한도를 합치거나 우회하지 않습니다. 가능한 공식 팀 멤버 기능을 쓰고, 제공사가 본인 전용으로 정한 키는 공유하지 않습니다.
5. AI는 이 문서를 읽고 해당 담당의 준비 상태를 먼저 확인합니다. 본인 인증·결제·유료 체험·실제 발송 등은 문서의 체크박스만으로 완료/허가됐다고 간주하지 않습니다. 수집기를 외부로 연결할 때는 해당 사용자의 요청과 제공사 허용 범위를 확인합니다.

공식 페이지 확인과 실제 계정 승인·발급·응답을 구분합니다. 11월9일 HJNC 공개 응답과 도로공사 발급 안내는 확인했지만 팀원의 도로공사 키 발급·실응답은 미확인입니다. 기존 문의 회신 확인 결과와 공개 조회의 한계는 진행표에 따로 남겼습니다.
