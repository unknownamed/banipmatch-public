# API 사전 신청·준비 안내

기준일: **2026-11-07 (한국시간)**. 담당자와 준비 순서를 정한 문서이며, 가입·키 발급·승인이 완료됐다는 기록은 아닙니다. 상태는 [진행표](api-access-status.md)에 증거와 함께 갱신합니다. 본인의 개발 역할과 병행하며, 첫 모의 시연은 외부 API를 기다리지 않고 만듭니다.

## 누가 무엇부터 할지

| 담당 | 지금 맡을 준비 | 조건을 갖춘 뒤 이어갈 후보 |
|---|---|---|
| **심민준 · 데이터** | 체인포털 일반회원·현행 API 신청 경로 확인, HJNC에 필요한 필드 정리, 기상청 일반회원·키 준비 | 공공데이터포털의 현행 항만·도로 자료, 허용된 실응답의 표준화 |
| **최길웅 · 프론트** | 카카오맵 팀 앱 1개 준비, 무료 적용 여부·로컬 도메인 확인 | 배포 도메인 추가, 일반/위성 전환. 길찾기는 지도와 별도 권한·기능인지 선효와 확인 |
| **안선효 · API·통합** | AISstream 계정·서버용 키 준비, 서비스별 키·호출량·오류 처리 방식 정리 | 자동차 길찾기, 문자 발신번호 절차. 결제·실제 문자 발송은 별도 결정 |
| **황대겸 · 엔진·팀장** | 기존 BPA·HJNC·SeaVantage 문의/회신 정리와 창구 조율. 엔진은 외부 키 없이 계속 개발 | SeaVantage 시험 API 협의, ShipsGo 대체 후보 검토. 체험은 데이터·시험 일정에 맞춰 시작 |

신청 담당과 실제 계정 명의자는 다를 수 있습니다. 예전 대겸 계정으로 진행한 서비스는 대겸이 직접 인증하고, 다른 사람이 비밀번호나 인증번호를 받아 대신 관리하지 않습니다. 팀 멤버 기능과 이용조건을 먼저 확인합니다.

## 우선순위와 준비 마감

- **A · 지금 권한·신청 경로 확인:** 체인포털/HJNC, SeaVantage. 별도 승인·기관 협의가 필요할 수 있어 먼저 담당을 둡니다. 이미 보낸 문의와 연결하며 같은 문의를 여러 명이 중복 발송하지 않습니다.
- **B · 지금 무료 계정·키·설정 준비:** 카카오맵, 기상청, AISstream. 이후 지도·기상·선박 보조 기능을 채택할 때 바로 시험할 수 있게 합니다. 조건 확인 중 유료 전환이 필요하면 결제하지 않고 진행표에 기록합니다.
- **C · 자료·기능을 정한 뒤 활성화:** ShipsGo 실제 추적, 자동차 길찾기/도로 통행시간의 엔진 반영, SOLAPI 실제 발송. 지금 담당자는 조건과 신청 경로를 확인하고, 기간제 체험·유료 호출은 무작정 시작하지 않습니다.

**팀 내부 목표:** 다음 작업 세션에 A/B 준비를 시작하고 **11월 8일까지** 신청 가능/진행 중/막힌 이유 중 하나를 진행표에 남깁니다. 외부 업체의 승인 완료 기한을 뜻하지 않습니다. 기한까지 승인되지 않아도 모의 입력과 수동 확인값으로 개발합니다. 추가 문의가 필요하면 먼저 기존 담당 창구와 내용을 맞춥니다.

## A1 · 체인포털 / BPA — 심민준, 대겸 협조

- **링크:** [가입·로그인](https://www.chainportal.co.kr/main/ko) · [Port-i 비회원 체험](https://www.chainportal.co.kr/portiweb/ko/trial) · [BPA 개인회원 이용 안내](https://www.busanpa.com/board/view.bpa?boardId=BBS_0000031&dataSid=34863&menuCd=DOM_000000105002001000) · [공식 API 매뉴얼](https://www.chainportal.co.kr/manual/download?filename=Chainportal-TIS-Manual.pdf).
- **용도:** HJNC 항차 연결, 확인된 반입 시작·마감과 변경 이력의 제공 가능성 확인. 선석·본선 시각은 보조 자료입니다.
- **순서:** 일반회원 가입/로그인 상태 확인 → Port-i/IIS의 실제 메뉴 확인 → 현행 Open API 신청 메뉴와 사용 가이드 확인 → 필요한 터미널·API·사용시스템명/URL을 정확히 적어 신청 가능한 항목만 진행.
- API 신청 매뉴얼은 **2021년판**입니다. 신청/승인/반려와 HJNC 선택 항목이 있지만, 현재 학생 권한·필드·메뉴가 같다고 보장하지 않습니다. 메뉴가 없으면 화면 상태를 기록해 기존 BPA 문의에 합칩니다. 존재하지 않는 배포 URL·업체정보를 만들지 않습니다.
- **대기·한도:** 현행 승인 소요일, 학생 승인 자격, API 한도·비용은 미확인입니다. 일반회원 가입과 API 승인은 별개입니다.
- **현재 기록:** 대겸은 과거 본인인증 뒤 가입 완료를 확인하지 못했습니다. BPA 자문은 이미 발송했습니다. 이번 문서 작성 중 로그인·신청·회신 확인은 하지 않았습니다.

## A2 · HJNC 연구용 접근 — 심민준 요구사항, 대겸 연락 창구

- **링크:** [정보조회](https://e-service.hjnc.co.kr/esvc) · [가입 양식](https://e-service.hjnc.co.kr/esvc/membership/memberInfo) · [공식 담당 부서](https://e-service.hjnc.co.kr/board/contact).
- **지금 할 일:** 기존 자문 문의와 연결해 연구용 읽기 전용 API/계정 또는 비식별 표본을 받을 수 있는지 정리합니다. 필요한 항목은 확정 반입시간·변경 시각·항차 ID·공지 근거가 우선입니다. 차량 방문/적·공컨 상태 예시는 추가 요청 후보입니다.
- **가입 조건:** 공식 양식에 회사명·사업자등록번호·업체종류가 필수입니다. 학생이 업체 정보를 임의 입력하지 않습니다. 가입이 곧 API 제공 승인은 아닙니다.
- **대기·한도:** 학생용 경로·승인일수·호출량은 미확인입니다. 수집 빈도, 보관기간, 보고서·공개 시연·재배포 범위를 확인합니다. 공개표가 보인다는 사실만으로 자동 수집을 허용받았다고 처리하지 않습니다.
- **대안:** 허용 범위에서 확인자가 읽은 반입시간과 출처·확인시각을 입력합니다. 실제 운송사 배차표와 트럭 GPS는 별도 제공 협조가 필요합니다.

## A3 · SeaVantage — 황대겸, 데이터 확인은 심민준

- **링크:** [Cargo Insight](https://www.seavantage.com/cargo-insight) · [요금·영업 문의](https://www.seavantage.com/pricing) · [개발 문서](https://developer.seavantage.com/).
- **용도:** 선박/화물 사건과 ETA 등 보조 정보의 시험 가능성 확인. 추적 위치나 ETA를 확정 반입마감으로 바꾸지 않습니다. 제공사가 원인 필드를 준다는 사실만으로 모든 지연 원인이 확인되는 것도 아닙니다.
- **지금 할 일:** 대겸이 이미 보낸 시험 API 문의 기록과 회신을 확인하고, 필요하면 허용 표본·개인 학생 시험 자격·기간·호출량·비용·공개 시연 조건의 빠진 질문을 정리합니다. 새 문의를 자동 재발송하지 않습니다.
- 공식 요금표의 **웹 체험 7일/10컨테이너**는 API 승인/무료 한도가 아닙니다. API+화면 삽입은 영업 문의 항목입니다. API 승인 소요일·학생 시험 한도는 미확인입니다. 구현·표본 준비 전에 기간제 웹 체험을 소모하지 않습니다.

## B1 · 카카오맵 Web SDK — 최길웅

- **링크:** [개발자 계정·앱](https://developers.kakao.com/) · [활성화 절차](https://developers.kakao.com/docs/ko/kakaomap/common) · [Web SDK 시작](https://apis.map.kakao.com/web/guide/) · [멤버 관리](https://developers.kakao.com/docs/ko/app-setting/app#member) · [쿼터](https://developers.kakao.com/docs/ko/getting-started/quota).
- **준비 순서:** 개발자 등록 → 팀 앱 생성 → 소유자의 기존 지도 활성화 이력 확인 → 무료 적용 대상이면 카카오맵 ON → JavaScript 키에 실제 로컬 개발 도메인 등록 → 지도 한 장 표시. 배포 URL은 결정 후 추가합니다.
- **중요:** 개발자 계정에서 처음 활성화한 지도 앱에 무료 쿼터가 적용됩니다. 두 번째 앱이거나 무료량을 넘기면 유료 설정이 필요할 수 있습니다. 무료 뱃지를 먼저 확인하며, 무조건 무료라고 가정하지 않습니다.
- **팀 사용:** 공식 멤버 기능을 사용합니다. JavaScript 키는 브라우저용이므로 도메인 제한을 적용하고, REST/어드민 비밀키는 프론트에 넣지 않습니다. 키 값은 Git·카톡·AI 채팅에 붙이지 않습니다.
- **한도·대기:** 문서상 Web SDK 일 300,000건, 전체 API 무료 월 3,000,000건을 함께 확인합니다. 앱 기준이며 조원별 키로 합산 증설하지 않습니다. 일반 활성화 절차는 있으나 처리시간 SLA는 확인하지 못했습니다.
- 지도는 배경입니다. 실제 차량 GPS·선박 위치·화물 추적 자료를 공급하는 API가 아닙니다.

## B2 · 기상청 API허브 — 심민준

- **링크:** [일반회원 가입](https://apihub.kma.go.kr/join.do) · [이용·키 안내](https://apihub.kma.go.kr/apiInfo.do) · [해양기상부이](https://apihub.kma.go.kr/apiList.do?seqApi=3) · [기상특보](https://apihub.kma.go.kr/apiList.do?seqApi=10&seqApiSub=288) · [약관](https://apihub.kma.go.kr/policy.do).
- **준비 순서:** 본인 이메일로 일반회원 선택 → 본인 가입 → 마이페이지 키 확인 → 부산 신항 인근 관측지점·특보구역과 시간대 확인 → 허용된 소량 응답을 확인해 이용조건과 필드 기록. 기관회원은 공문·관리자 승인 경로이므로 학생 개인 신청과 혼동하지 않습니다.
- **대기·한도:** 공식 안내상 일반회원은 자동 가입·키 발급입니다. 일 20,000요청/5GB이며 시스템 상황 등에 따라 달라질 수 있습니다. 모든 API가 며칠씩 대기한다고 설명하지 않습니다.
- **키 소유:** 본인만 사용하고 양도·대여하지 않는 조건입니다. 민준이 소유·수집을 맡고 선효에게 키를 전달하지 않습니다. 공용 서버 운용 가능 여부가 불명확하면 본인 환경에서 수집한 허용 자료나 모의 응답으로 연결합니다.
- 기상은 시각·구역을 함께 보여주는 보조 근거입니다. 악천후와 지연이 겹쳤다는 이유만으로 지연 원인을 확정하지 않습니다.

## B3 · AISstream — 안선효, 심민준과 자료 형식 확인

- **링크:** [GitHub 로그인·키 관리](https://aisstream.io/account) · [가입 순서](https://aisstream.io/) · [서버 연결·제한](https://aisstream.io/documentation).
- **준비 순서:** 본인 GitHub로 로그인 → API 키 생성 → 키는 본인 서버 환경에 보관 → 부산 신항 주변의 작은 해역으로 짧은 수신 시험 계획. 등록/발급만 하고 실제 장시간 수집을 켜 두지 않습니다.
- **대기·한도:** 공개 안내는 로그인 후 키 생성 절차이며 승인 기간 보장은 없습니다. 계정당 구독 연결 3개, 출발 IP당 연결 3개 제한을 함께 적용합니다. 일/월 수신 총량 숫자는 미확인입니다.
- **연결:** 브라우저 직접 연결은 허용되지 않으므로 서버가 받고 화면에는 필요한 데이터만 전달합니다. 표시·저장·발표 허용 조건과 원하는 해역의 실제 수신 범위를 확인해야 합니다.
- AIS는 선박 관측입니다. 트럭·개별 컨테이너 GPS가 아니며 중국 연안/항만에서 항상 끊김 없이 받을 수 있다고 보장하지 않습니다. MMSI와 IMO·항차 ID 연결 및 관측시각을 보존합니다.

UNI-PASS 수입 통관, 실차 GPS·기업 배차표, 게이트 전체 기록은 현재 신청을 밀어붙일 항목이 아닙니다. 본 주제는 수출 반입 조정이고, 데이터 권한·파트너·식별자가 필요합니다. 실제 기회가 생기면 별도 후보로 추가합니다.

## 신청 목적에 쓸 공통 문장

> 국립창원대학교 컴퓨터공학과 학생팀 반입맞춤입니다. 스마트물류 경진대회에 참가해 보고서와 발표, 모의 시제품을 준비하고 있습니다. 부산항 신항 수출 컨테이너의 확인된 반입시간 변경에 대응해 배차 조정안을 비교하려 합니다. 허용된 자료를 읽기 전용으로 사용하고, 수집 빈도·보관기간·대회 발표 및 시연 범위는 제공기관 조건에 따르겠습니다. 현재 실제 운송사 배차표와 실화물 식별번호는 확보하지 못했습니다.

서비스마다 필요한 필드와 목적을 추가합니다. 웹사이트가 없으면 임의 주소를 만들지 말고 로컬 개발 단계임을 밝힙니다. 비공개 저장소 링크를 상대가 열람할 수 있다고 가정하지 않습니다.

## 준비 완료로 인정할 것

1. **가입**, **API 신청 접수**, **승인/키 발급**, **허용된 응답 수신**을 별도 상태로 기록합니다.
2. 신청한 서비스/필드, 신청일, 공식 승인 예상기간(없으면 미확인), 다음 확인일, 비용·한도·키 사용 주체·표본/발표 이용조건을 진행표에 남깁니다.
3. 키·OTP·비밀번호·개인 식별값이 없는 화면/요약만 저장합니다. 실제 화물 원본은 허용 범위와 공개 범위를 검토한 뒤 취급합니다.
4. 계정·키를 여러 개 만들어 한도를 합치거나 우회하지 않습니다. 가능한 공식 팀 멤버 기능을 쓰고, 제공사가 본인 전용으로 정한 키는 공유하지 않습니다.
5. AI는 이 문서를 읽고 해당 담당의 준비 상태를 먼저 확인합니다. 본인 인증·결제·유료 체험·실제 발송 등은 문서의 체크박스만으로 완료/허가됐다고 간주하지 않습니다. 수집기를 외부로 연결할 때는 해당 사용자의 요청과 제공사 허용 범위를 확인합니다.

공식 페이지 확인과 실제 계정 사용 시험을 구분합니다. 체인포털의 현행 로그인 메뉴, 각 팀원 계정의 키 발급 여부, 업체 회신은 이번 문서 작성에서 확인하지 않았습니다. 새 조건이나 회신이 오면 이 문서와 진행표를 함께 갱신합니다.
