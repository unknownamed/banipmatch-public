# ORS Matrix 첫 응답 검증 · 길웅 #37

확인일 2026-11-11. openrouteservice(HeiGIT) 개인 무료 계정을 본인 명의로 가입하고 키를 발급받아 **1회** 소량 시험했다. 키 값은 저장소·로그·이슈·AI 대화에 넣지 않았다. 키는 계정 소유자 PC의 Git 제외 파일(`local/`)에만 있다. 이 문서는 발급과 첫 응답의 기록이며, 배차 계산 입력으로 채택했다는 뜻이 아니다.

## 계정·한도

- 가입: [account.heigit.org/signup](https://account.heigit.org/signup), 이메일 개인 계정. 사업자·기관·카드 정보는 요구되지 않았다. 가입 화면에는 "1인 1계정·무료 키 1개, 중복 계정 삭제, 한도 반복 초과 시 키 정지"가 적혀 있다.
- 키 관리 화면의 하루 한도/분당 한도: Matrix V2 500/40, Directions V2 2,000/40, Isochrones V2 500/20, Snap V2 2,000/100, Geocoding 3,000/100, Optimization 500/40, POIs 500/60. [팀 안내](../team/personal-api-signup.md#ors-standard--길웅-선효대겸-협조)의 Standard 한도와 같다. 화면에서 플랜 이름 표기는 따로 보지 못했다.
- 시험 응답 헤더 `x-ratelimit-limit: 500`, `x-ratelimit-remaining: 499`.
- HeiGIT 서비스 점검 공지: 2026-11-14 15:00 ~ 11-15 01:00 KST.

## 요청

- `POST https://api.heigit.org/openrouteservice/v2/matrix/driving-hgv`. 새 기본 주소이며 종료된 `api.openrouteservice.org`는 쓰지 않았다.
- 본문: `locations`(좌표 순서는 [경도, 위도]), `metrics: ["duration", "distance"]`, `units: "m"`. 화물차 크기·중량 옵션은 지정하지 않았다.
- 지점은 공개 지도에서 고른 **근사 좌표**다. 터미널 게이트·상차지·차고지의 실제 좌표가 아니다.

## 응답 (HTTP 200, 수신 2026-11-11T06:51:05Z)

`durations`는 초, `distances`는 미터다. 행이 출발, 열이 도착이다.

| 출발 \ 도착 | 0 | 1 | 2 |
|---|---|---|---|
| 0 | 0 s · 0 m | 757.71 s · 8,580.79 m | 1,732.86 s · 24,577.32 m |
| 1 | 749.13 s · 8,843.02 m | 0 s · 0 m | 1,214.80 s · 18,056.54 m |
| 2 | 1,826.56 s · 26,217.10 m | 1,115.59 s · 16,949.76 m | 0 s · 0 m |

- 9칸 모두 값이 있다. `null`(경로 없음)은 이번 표본에 없었다. 앞으로 `null`이 오더라도 0이나 다른 방향 값으로 채우지 않는다.
- 방향마다 값이 다르다(예: 0→2는 1,732.86 s, 2→0은 1,826.56 s). 역방향을 복제해 행렬을 완성하지 않는다.
- 지점 0은 가장 가까운 도로까지 207 m를 옮겨 계산했다. 실제 게이트 좌표를 쓰면 값이 달라질 수 있다.
- 응답 메타데이터: 엔진 10.1.0, 그래프 2026-10-17, OSM 자료 2026-10-11. `attribution: openrouteservice.org | OpenStreetMap contributors`.

## 사용 조건과 한계

- 화면이나 산출물에 수치를 보여줄 때 `© openrouteservice by HeiGIT | Data from OpenStreetMap` 출처를 표시하고, [약관](https://account.heigit.org/info/tos)의 CC-BY-SA 4.0 조건을 따른다. Matrix 수치의 저장·재사용은 [운영자 답변](https://ask.openrouteservice.org/t/persistent-storage-and-reuse-of-matrix-api-duration-results/8010) 기준으로 약관 준수 조건에서 가능하다. 경로선(geometry)은 이번 범위가 아니다.
- **실시간 교통이 반영된 도착시각이 아니다.** 무료 API는 실시간 교통을 제공하지 않는다. 화물차 프로필도 OSM 제한 정보에 의존하므로 통행 가능성의 인증이 아니다.
- 근사 좌표 3개 · 1회 표본이다. 부산항 전체 구간의 품질, 시간대별 차이, 실제 트럭 운행시간과의 차이는 검증하지 않았다.
- 숫자 결과 원본은 계정 소유자 PC의 `local/`에만 있다. 이 문서의 표가 공유용 기록이다.
