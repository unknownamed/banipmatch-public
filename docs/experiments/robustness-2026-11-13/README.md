# 엔진 하드코딩 여부 점검 (2026-11-13)

- 목적: 화면 시연 입력에만 맞춰 둔 결과가 아니라, 바뀐 입력마다 엔진이 새로 계산하고 그 결과가 업무 규칙을 지키는지 확인한다.
- 방법: `frontend/src/fixtures/demo-02-evening.synthetic.json`을 무작위로 12번 바꾼다(준비 시각 일부 -60~+90분, 새 반입 마감 -60~+60분, 50% 확률로 출발 작업 없는 차량 1대 운행 불가). 각 입력을 B1·B3(3초)로 계산한다.
- 검사기(엔진과 별도 코드, `tools/check_engine_robustness.py`): 작업 누락·중복, 고정 작업 보존, 준비 전 출발, 이동시간, 마감·근무 초과(엔진이 문제로 표시하지 않은 경우), 장비·중량, 차량 일정 겹침.
- 결과(`result.txt`): 24회 모두 서로 다른 배차, B3는 모두 OPTIMAL, 표시되지 않은 규칙 위반 0건. 미배정 0~6건으로 입력에 따라 달라짐.
- 한계: 같은 시연 지역·차량 구성에서 값만 바꾼 점검이다. 다른 지역·대규모 입력은 `docs/experiments/engine-profile-2026-11-08`를 본다.

실행: `python tools/check_engine_robustness.py .`
